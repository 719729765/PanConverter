# 网盘链接自动转换器

一款面向 Windows 的轻量级剪贴板辅助工具。复制网页、文章或 WordPress 编辑器中的内容后，程序会自动识别常见网盘链接，提取链接并整理成统一格式；识别到百度网盘提取码时，还会尝试把提取码补进链接参数。

> **项目定位：** 本工具只负责从剪贴板中提取、识别和整理网盘链接，不负责登录网盘、验证链接是否有效、绕过访问限制或下载文件。

## 功能概览

- **自动监控剪贴板：** 默认每约 `0.35` 秒检查一次剪贴板变化。
- **同时读取文本和 HTML：** 适用于复制普通文字、网页正文、包含超链接的网页片段以及部分富文本编辑器内容。
- **识别常见网盘：** 根据链接域名判断网盘类型，并按统一格式输出。
- **提取百度网盘提取码：** 尝试识别“提取码：abcd”“密码：abcd”“pwd=abcd”等常见写法，并在百度网盘链接尚未包含 `pwd` 参数时补上。
- **解析部分二维码图片链接：** 可尝试从 `api.qrserver.com`、`quickchart.io` 的 `data` 参数中取出嵌入的链接。
- **自动复制转换结果：** 成功识别后，默认将结果写回系统剪贴板，方便直接粘贴到文章或后台。
- **避免重复处理：** 已经是本工具输出格式的内容会被跳过；同一轮提取到的重复链接会去重。
- **可选输出后缀：** 可在主界面或托盘菜单切换是否追加 `|jy=laoquzhang.com`。
- **后台托盘运行：** 点击窗口关闭按钮不会直接退出，而是隐藏到 Windows 通知区域；双击托盘图标可恢复窗口，右键可打开操作菜单。
- **手动操作：** 提供“立即读取剪贴板”“复制转换结果”和“清空”按钮，也可以暂停自动监控。
- **原生 Windows API 剪贴板访问：** 使用 `ctypes` 读写 Unicode 文本及 HTML 剪贴板数据。

## 转换结果格式

默认开启后缀追加时，每条结果使用以下格式：

```text
网盘名称|网盘链接|jy=laoquzhang.com
```

例如，复制内容中包含百度网盘链接和提取码后，输出可能类似：

```text
百度网盘|https://pan.baidu.com/s/示例链接?pwd=abcd|jy=laoquzhang.com
夸克网盘|https://pan.quark.cn/s/示例链接|jy=laoquzhang.com
```

以上链接仅为格式示例，不是真实分享地址。关闭后缀追加后，输出会变成：

```text
百度网盘|https://pan.baidu.com/s/示例链接?pwd=abcd
```

### `jy=laoquzhang.com` 是什么？

这是源码中设置的**自定义文本后缀**，由 `UNZIP_PWD = "laoquzhang.com"` 控制。程序只是把它追加到转换结果中，**不会验证压缩包密码，也不会访问该网站或自动解压文件**。如果你不需要这个标记，可以在程序界面或托盘菜单中关闭后缀追加。

## 使用方法

### 1. 启动程序

下载发布页中的可执行文件（如果项目发布了 EXE），双击运行即可。首次运行时，Windows 可能显示安全提示；请先确认文件来源可信，再决定是否运行。

如果你下载的是 Python 源码，请参阅下方的“从源码运行”。

### 2. 自动转换

1. 启动程序，确认状态栏显示正在监控系统剪贴板。
2. 在浏览器网页、文章页面或 WordPress 编辑器中，选中并复制包含网盘链接的内容。
3. 程序会检查剪贴板文本及 HTML 中的链接。
4. 识别到支持的网盘后，结果会显示在“转换结果”区域，并默认自动复制到剪贴板。
5. 切换到需要粘贴的编辑器或后台，按 `Ctrl + V` 即可使用结果。

**注意：** 自动复制会用转换结果替换当前剪贴板内容。若你复制的是重要文本，请留意转换后剪贴板内容的变化。

### 3. 手动转换

- **立即读取剪贴板：** 重新读取当前剪贴板并尝试转换。
- **复制转换结果：** 把结果框中的文本复制到剪贴板。
- **清空：** 清空界面文本框，不会删除网页内容或文件。
- **自动监控 / 自动转换：** 暂停或恢复自动检测。
- **追加后缀：** 控制每条结果是否追加 `|jy=laoquzhang.com`。

### 4. 使用系统托盘

- 单击窗口右上角关闭按钮：隐藏主窗口，程序继续在后台运行。
- 双击通知区域中的程序图标：恢复主窗口。
- 右键托盘图标：可显示窗口、暂停/恢复自动转换、切换后缀追加或退出程序。
- 如需完全退出，请使用托盘菜单中的“退出程序”，不要只关闭主窗口。

- Windows 10 / Windows 11
- Python 3（建议使用较新的 64 位官方发行版）

本项目目前使用 `ctypes`、`tkinter`、`threading`、`re`、`html`、`time` 和 `urllib.parse` 等标准库模块，源码本身**不需要额外安装第三方 Python 依赖**。如果 Python 安装时未包含 Tcl/Tk，主界面可能无法启动。

如果命令提示“不是内部或外部命令”，请先安装 Python，并在安装时启用将 Python 添加到 `PATH` 的选项；也可以使用已安装 Python 的完整路径运行脚本。

## 工作流程

```text
复制网页内容
      ↓
读取剪贴板文本 + HTML
      ↓
提取 URL 与部分 HTML 链接属性
      ↓
识别支持的网盘域名
      ↓
尝试提取百度网盘提取码并补充 pwd 参数
      ↓
```

## 常见问题

### 没有识别出网盘链接怎么办？

确认复制的内容里确实包含完整的 `http://` 或 `https://` 链接，并检查域名是否在支持范围内。某些网页只复制了标题、图片或脚本内容时，剪贴板中可能没有可识别的原始 URL。也可以点击“立即读取剪贴板”重新尝试。

### 百度网盘提取码没有自动补上？

程序只尝试识别剪贴板文本中常见的提取码写法，例如 `提取码：abcd`、`提取码 abcd`、`pwd=abcd` 或 `密码：abcd`。提取码长度和字符不符合当前匹配规则、网页没有复制到提取码，或链接已经带有 `pwd` 参数时，都可能不会补充。

### 为什么转换结果没有重复执行？

程序会检查剪贴板内容是否已经符合工具的目标格式；如果识别为已转换结果，就会跳过，以免反复追加后缀或重复转换。

### 关闭窗口后，程序为什么还在运行？

这是预期行为：关闭主窗口会将程序隐藏到系统托盘。请右键托盘图标，选择“退出程序”才会完全退出。

### `jy=laoquzhang.com` 能当作所有网盘的提取码吗？

不能。它只是输出行末尾的自定义标记。程序只会在识别到百度网盘相关提取码时尝试添加 `pwd` URL 参数；不会自动把这个后缀应用为各网盘的密码，也不会验证任何密码是否正确。

### 为什么“最近检测到的内容”框可能没有显示内容？

当前提供的源码创建了该文本框，但未看到自动把原始剪贴板内容写入该框的更新逻辑。若运行时该区域为空，这属于当前源码实现的限制，不影响核心链接转换流程；若希望显示原始内容，需要在监控或手动读取逻辑中补上界面更新。

## 当前限制与注意事项

- **仅支持 Windows：** 代码直接调用 `user32`、`kernel32` 和 `shell32` 等 Windows API，不适用于 macOS 或 Linux。
- **不保证所有网页都能提取：** 取决于应用写入剪贴板的数据格式、复制方式和 URL 是否以可识别形式存在。
- **不验证链接状态：** 不会检查链接是否过期、是否需要登录、是否有权限或提取码是否正确。
- **不下载文件：** 不会主动连接网盘服务器执行下载任务。
- **剪贴板会被自动替换：** 成功转换时，默认把结果写入系统剪贴板；请避免在剪贴板中暂存不希望被程序覆盖的内容。
- **程序会读取剪贴板：** 自动监控开启时，程序会在本机读取剪贴板文本及 HTML 内容以执行匹配。请不要在不信任的设备上使用，也不要复制不希望被本机程序处理的敏感信息。

## 隐私说明

从当前源码看，程序没有实现向远程服务器上传剪贴板内容的网络请求；主要处理均在本地完成。但它会持续读取系统剪贴板，并可能用转换结果覆盖剪贴板。使用者应了解这一行为，按需暂停自动监控或退出程序。后续若加入联网、日志上传或更新检查功能，应同步更新本节说明。
